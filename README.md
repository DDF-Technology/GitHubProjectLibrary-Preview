# GitHub Project Library — Demo Read-Only

Questa è una versione dimostrativa pre-release per Windows 10/11 x64. Riproduce l'interfaccia della versione completa e permette di collegare il proprio account GitHub per consultare repository, dashboard, statistiche e README reali.

La Demo non legge repository o directory locali. Clone, fetch, pull, scansione locale, apertura degli strumenti e generazione del prompt sono visibili ma disabilitati; le relative implementazioni non sono incluse nel pacchetto. La Demo non può essere trasformata in Full modificando impostazioni o file di configurazione.

## Avvio

1. Estrarre interamente l'archivio ZIP.
2. Avviare `GitHubProjectLibrary-Demo.exe`.
3. Nelle Impostazioni, inserire un Personal Access Token GitHub limitato ai repository desiderati e ai permessi di sola lettura.
4. Questa anteprima non è firmata digitalmente: Windows può mostrare un avviso di sicurezza. Prima
   di procedere, confrontare il checksum SHA-256 del file scaricato con quello pubblicato sul sito.

Non è necessario installare .NET. La distribuzione è portable e self-contained.
